
# 🗺️ Text-Based Adventure Game

Welcome to the **Adventure Game**! A fun, interactive, and text-based Python game where your choices determine your destiny.

## 🎮 About the Game

You are standing in an open field, armed with only a dagger. Rumor has it that a wicked creature (randomly chosen) is terrorizing a nearby village. Will you explore the house? Or venture into the cave and find the legendary **Sword of Ogoroth**? Choose wisely. Fight bravely.

## 🚀 How to Run

**Requirements:**  
- Python 3.7 or higher

**To start the game:**  
Open your terminal and run:
```bash
python adventure_game.py
```
Follow the instructions and type your choices when prompted.

## 🔁 Replayability

Each game features a random enemy chosen from: pirate, troll, wicked fairie, dragon, or gorgon. Every playthrough feels slightly different!
